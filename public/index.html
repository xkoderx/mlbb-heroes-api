MLBB Heroes API

API pública con los héroes de Mobile Legends: Bang Bang (Moonton). En español, sin llave ni registro. Datos basados en p3hndrx/MLBB-API.

Cómo se usa

Todos los endpoints responden en JSON. No hace falta registrarse ni usar llave. Activa CORS, así que puedes llamarla directamente desde el navegador.

curl https://TU-DOMINIO/api/heroes?role=Marksman

Endpoints

GET /

Información de la API: nombre, versión y lista de endpoints.

GET /api/heroes

Lista de héroes, con filtros y paginación.

ParámetroQué haceEjemplo
roleFiltra por rol?role=Marksman
laneFiltra por línea?lane=gold lane
searchBusca por nombre (sin distinguir mayúsculas)?search=miya
limitResultados por página (por defecto 50, máximo 130)?limit=10
pageNúmero de página (por defecto 1)?page=2

La respuesta incluye total, page, limit, totalPages y el arreglo heroes.

GET /api/heroes?role=Marksman&limit=2

{
  "total": 23,
  "page": 1,
  "limit": 2,
  "totalPages": 12,
  "heroes": [
    { "id": "h001", "slug": "miya", "hero_name": "Miya", "class": "Marksman", ... },
    ...
  ]
}

GET /api/heroes/:id

Un héroe por id (h001), por mlid (1) o por slug (miya).

GET /api/heroes/miya

{
  "id": "h001",
  "mlid": "1",
  "uid": "miya",
  "slug": "miya",
  "hero_name": "Miya",
  "class": "Marksman",
  "laning": ["gold lane"],
  "portrait": "https://akmweb.youngjoygame.com/...",
  "hero_icon": "miya.png",
  "release_year": null,
  "skills": [
    { "skill_name": "Moon Blessing", "type": "passive", "cooldown": "null", "description": "..." },
    ...
  ]
}

Si no existe, responde 404: { "error": "Héroe no encontrado" }

GET /api/roles

Los 6 roles del juego con la cantidad de héroes de cada uno.

GET /api/roles

{ "total": 6, "roles": [ { "role": "Fighter", "heroes": 44 }, ... ] }

GET /api/lanes

Las líneas del juego con la cantidad de héroes de cada una.

GET /api/lanes

{ "total": 5, "lanes": [ { "lane": "mid lane", "heroes": 28 }, ... ] }

GET /api/status

Estado de la API y cantidad de héroes en el dataset.

GET /api/status

{ "status": "ok", "heroes": 133, "version": "1.0.0", "fuente": "p3hndrx/MLBB-API" }

Valores posibles

Roles: Tank, Fighter, Assassin, Mage, Marksman, Support. Algunos héroes tienen dos roles (por ejemplo "Tank, Mage") y aparecen en ambos.

Líneas: gold lane, mid lane, exp lane, jungle, roam. También funcionan las formas cortas: gold, mid, exp.

Pruébala aquí mismo

Escribe una ruta y la API te responde en vivo (funciona cuando la API está corriendo en este mismo origen).

Pulsa "Probar" para ver la respuesta.

Ejemplo en JavaScript

const res = await fetch('/api/heroes?search=miya');
const data = await res.json();
console.log(data.heroes[0].hero_name); // "Miya"
